Guide just incase my team member does not know how to run or forgotten how to run the server

Make sure you have imported the SQL in your MySQL. If you already have, skip step 1.
1. the SQL to be imported is in the "./database backup"

2. npm install

3. find your .env file and change the database name on it to our database, then change the password to your MySQL password

4. npm run dev

in another terminal

5. php artisan serve
